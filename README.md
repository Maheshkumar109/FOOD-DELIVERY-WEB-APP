A simple and responsive Food Delivery Web Application that allows users to explore delicious meals, add them to cart, and place orders online — designed for a smooth and modern user experience.

🚀 Overview

This project is a frontend web application built to simulate an online food ordering platform.
Users can browse dishes, view details, and manage their cart seamlessly.

🧩 Features

🍕 Browse food items by category

🛒 Add, remove, and view items in the cart

💳 Simple order checkout flow

📱 Fully responsive design for mobile & desktop

⚡ Fast loading with modern UI components

🛠️ Tech Stack
Category	Technologies
Frontend	HTML, CSS, JavaScript
Framework / Library	React.js
Hosting / Deployment	Vercel
Styling	Tailwind CSS
